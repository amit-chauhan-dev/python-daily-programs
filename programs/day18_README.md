## Problem
Write a Python program to print the Fibonacci sequence up to n terms.

## Program Description
This Python program generates the Fibonacci sequence based on the number of terms entered by the user.

The Fibonacci sequence is a series where each number is the sum of the previous two numbers, starting from 0 and 1.

## Logic Used

- Initialize first two numbers: 0 and 1  
- Take number of terms as input  
- Handle special cases (≤ 0, 1 term)  
- Use a while loop to generate sequence  
- Update values in each iteration  

## Concepts Used

- Python input()
- While loop
- Conditional statements (if-elif-else)
- Variables
- Arithmetic operations
