## Problem
Write a Python program to check whether a given number is an Armstrong number.

## Program Description
This Python program checks if a number is an Armstrong number.

An Armstrong number is a number where the sum of its digits raised to the power of the number of digits is equal to the number itself.

## Logic Used

- Convert number to string to count digits  
- Loop through each digit  
- Raise each digit to power of total digits  
- Add all values  
- Compare result with original number
