## Problem
Write a Python program to find the sum of natural numbers up to a given limit.

## Program Description
This Python program calculates the sum of natural numbers from 1 up to a user-defined limit.

Natural numbers are positive integers starting from 1.

## Logic Used

- Take the limit as input  
- Check if the limit is valid (positive)  
- Initialize sum = 0  
- Loop from 1 to limit  
- Add each number to sum  
- Display the result  

## Concepts Used

- Python input()
- For loop
- Conditional statements (if-else)
- Arithmetic operations
