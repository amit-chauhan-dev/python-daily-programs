## Problem
Write a Python program to check whether a given number is odd or even.

## Program Description
This Python program takes an integer input from the user and checks whether the number is even or odd using the modulus operator.

If the number is divisible by 2, it is even. Otherwise, it is odd.

## Logic Used

If number % 2 == 0 → Even  
Else → Odd

## Concepts Used

- Python input()
- Integer data type
- Modulus operator (%)
- Conditional statements (if-else)
- Basic number logic
