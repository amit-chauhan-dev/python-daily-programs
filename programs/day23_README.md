## Problem
Write a Python program to find the HCF (Highest Common Factor) of two numbers.

## Program Description
This Python program calculates the HCF of two numbers entered by the user using a function.

HCF is the largest number that divides both numbers without leaving a remainder.

## Logic Used

- Take two numbers as input  
- Find the smaller number  
- Loop from 1 to smaller number  
- Check which numbers divide both inputs  
- Store the highest common factor  
- Return the result  

## Concepts Used

- Python functions
- For loop
- Conditional statements (if)
- Modulus operator (%)
- User input
