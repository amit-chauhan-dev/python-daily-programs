## Problem
Write a Python program to find the LCM (Least Common Multiple) of two numbers.

## Program Description
This Python program calculates the LCM of two numbers entered by the user using a function.

LCM is the smallest number that is divisible by both input numbers.

## Logic Used

- Take two numbers as input  
- Find the greater number  
- Loop until a number divisible by both is found  
- Return that number as LCM  
- Handle special case when any number is 0  

## Concepts Used

- Python functions
- While loop
- Conditional statements (if-else)
- Modulus operator (%)
- User input
