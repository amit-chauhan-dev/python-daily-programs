## Problem
Write a Python program to display all the prime numbers within a given interval.

## Program Description
This Python program displays all prime numbers between a fixed range.

In this program, the lower and upper limits are predefined as:
- Lower = 1
- Upper = 10

The program loops through each number in the range and checks whether it is a prime number.

## Logic Used

- Loop through numbers from lower to upper limit  
- Check if the number is greater than 1  
- For each number, check divisibility from 2 to number-1  
- If divisible → not a prime number  
- If not divisible → prime number  

## Concepts Used

- Python loops (for loop)
- Nested loops
- Conditional statements (if)
- Modulus operator (%)
