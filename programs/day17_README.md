## Problem
Write a Python program to display the multiplication table of a given number.

## Program Description
This Python program takes a number as input from the user and prints its multiplication table from 1 to 10.

## Logic Used

- Take a number as input  
- Loop from 1 to 10  
- Multiply the number with each value  
- Display the result  

## Concepts Used

- Python input()
- Integer data type
- For loop
- Arithmetic operations
- f-string formatting
