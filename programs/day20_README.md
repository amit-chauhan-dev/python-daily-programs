## Problem
Write a Python program to find all Armstrong numbers within a given interval.

## Program Description
This Python program takes a range (lower and upper limits) from the user and prints all Armstrong numbers within that range.

An Armstrong number is a number where the sum of its digits raised to the power of the number of digits is equal to the number itself.

## Logic Used

- Take lower and upper limits as input  
- Loop through each number in the interval  
- Skip negative numbers  
- Count number of digits  
- Extract digits and calculate sum of powers  
- Compare result with original number  
- Print Armstrong numbers  
 

## Concepts Used

- Python input()
- For loop
- While loop
- Conditional statements (if)
- Arithmetic operations
- String conversion
