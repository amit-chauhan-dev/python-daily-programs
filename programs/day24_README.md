## Problem
Write a Python program to convert a decimal number into binary, octal, and hexadecimal formats.

## Program Description
This Python program takes a decimal number as input from the user and converts it into:

- Binary
- Octal
- Hexadecimal

The program uses Python built-in conversion functions.

## Logic Used

- Take decimal number as input  
- Use:
  - bin() for binary conversion  
  - oct() for octal conversion  
  - hex() for hexadecimal conversion  
- Remove default prefixes for cleaner output  
- Display converted values  

## Concepts Used

- Python input()
- Built-in functions
- String slicing
- f-string formatting
- Number system conversion
